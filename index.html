MOBILE REGRESSION01

Finda Automation

PAIN POINT
LLM이 한국어 시나리오를 매번 다르게 해석해서 실패 원인을 추적하기 어려웠고, OS 차이로 시나리오가 나뉘기 시작했습니다.
APPROACH
오픈소스 Go 러너를 포크해 테스트는 YAML로 고정하고, OS 차이는 드라이버에서, LLM은 실패 복구에만 쓰도록 재구성했습니다.
STACK
Go · UIAutomator2 · WebDriverAgent · Python · Vault · Codex CLI
RESULT
플로우 44개 · 스텝 약 3,300개를 하나의 YAML로 두 OS에서 실행합니다. 회귀 시간은 Android 약 79%, iOS 약 51% 줄었습니다.
